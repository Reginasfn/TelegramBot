# 🎬 Telegram PopсornBot 🍿

## Описание проекта
Telegram PopсornBot — это Telegram-бот, который помогает пользователю находить интересные фильмы.  

Бот использует внешние API и модели искусственного интеллекта для получения информации о фильмах, умного поиска и ответов на вопросы пользователя.

## Используемое API

В проекте используется API:

### TMDB API (The Movie Database)

  TMDB (The Movie Database)  — мощное и популярное API для получения информации о фильмах и сериалах.
Почему TMDB API:
  - Богатство данных: Предоставляет широкий спектр информации: названия, описания, рейтинги, жанры, актёры, режиссёры, постеры, трейлеры.
  - Актуальность: База данных регулярно обновляется.
  - Документация и стабильность: Хорошо документированное, стабильное и надёжное API.
  - Локализация: Поддерживает русский язык для названий и описаний.

С его помощью бот может получить всю основную и необходимую информацию о фильме:

- название фильма
- описание
- рейтинг
- жанры
- режиссёра
- актёров
- постер фильма
- трейлер

Официальный сайт API:  
https://www.themoviedb.org/documentation/api

## Используемая модель ИИ

В проекте используется:

### Deepseek

Deepseek применяется для обработки вопросов пользователя о фильмах.  
Пользователь может нажать кнопку «Спросить ИИ» под карточкой фильма и задать вопрос, на который отвечает модель.

ИИ помогает:

- объяснить сюжет фильма
- рассказать интересные факты
- ответить на вопросы пользователя

### Трансформеры: SentenceTransformers (Semantic Search)

В боте реализован интеллектуальный поиск фильмов по смыслу пользовательского запроса с использованием модели all-MiniLM-L6-v2.

#### Описание работы трансформеров

1. Пользователь вводит описание фильма в свободной форме *(например: «фильм про космос и одиночество»)*
2. Бот получает список популярных фильмов через API TMDB
3. Для каждого фильма берётся его описание (overview)
4. Модель Transformer:
   - преобразует текст запроса и описания фильмов в векторные представления (эмбеддинги)
   - вычисляет семантическую близость между ними
5. На основе полученных оценок выбираются наиболее релевантные фильмы (ТОП-N)
6. Пользователь получает подборку фильмов, максимально соответствующих смыслу запроса

- Поиск работает по смыслу, а не по ключевым словам
- Учитывает контекст и формулировку пользователя
- Позволяет находить фильмы даже при неточном описании

## Используемые технологии

В проекте использованы следующие технологии:
- Python
- aiogram — библиотека для создания Telegram-ботов
- TMDB API — получение информации о фильмах
- Deepseek — обработка вопросов пользователя
- SentenceTransformers — семантический поиск фильмов (all-MiniLM-L6-v2)
- Hugging Face Transformers — работа с трансформер-моделями
